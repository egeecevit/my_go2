Detailed Description

Behavioral module that implements a rectangular body trajectory.

This module implements a simple rectangular body motion by commanding all legs to draw identical rectanges under their respective hips. The trajectory is generated by using the Profiler class, and individual legs are commanded to follow the trajectory by using the MdlLegControl module through inverse kinematics.

Note that this module also implements an example of a state machine with three states: WAIT, PREPLEGS, and DRAWSQUARE. The WAIT state is inhabited for a certain duration, followed by the PREPLEGS state, which prepares the legs to go to the initial corner of the rectangular trajectory from their current positions. Finally, the DRAWSQUARE state is entered, which commands the legs to indefinitely follow the periodic, rectangular trajectory.

Finally, this module also demonstrates configuration through TOML files, with entries under the [drawsquare] table configuring various aspects of the behavior parametrically.
